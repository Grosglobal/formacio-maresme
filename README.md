# Sabateria del Maresme · el cervell de l'empresa

Exemple per a la formació «Crea continguts professionals amb IA» (Consell Comarcal del Maresme, 25-nov-2026).

Aquí viu tot el que la IA ha de saber per treballar per a l'empresa:

- `marca/` · qui som, com parlem i com ens veiem.
- `clients/` · qui ens compra i què li agrada.
- `playbooks/` · processos de l'empresa, pas a pas.
- `skills/` · un saber fer empaquetat perquè la IA el faci sempre igual.

Tot és text simple (Markdown): el llegeixen igual les persones i la IA.
